# PSCoMiXX Desktop Hub

Native desktop wrapper for pscomixx.com built with **Tauri 2**.

This is a thin shell that loads the live web app inside a native window — same backend, same database, same auth. Updates to the web app appear in the desktop app on next launch with no re-release. Re-release the desktop app only when you change native behavior (window chrome, system tray, file associations, deep links).

## Architecture

```
desktop/
├── package.json              # Tauri CLI wrapper
├── dist/index.html           # Fallback splash (real UI loads from pscomixx.com)
└── src-tauri/                # Rust shell
    ├── Cargo.toml
    ├── tauri.conf.json       # Window, bundle, updater config
    ├── capabilities/         # Tauri 2 permission system
    ├── icons/                # Generated by `npm run icon` (gitignored)
    └── src/
        ├── main.rs
        └── lib.rs            # Tauri Builder + plugins
```

## One-time setup (only on a real Mac/Windows/Linux machine, NOT in Replit)

You don't build the desktop app from Replit — Replit hosts the source. Real builds happen on your laptop or in GitHub Actions.

### 1. Install prerequisites

| OS | Required tools |
|---|---|
| Mac | Xcode Command Line Tools (`xcode-select --install`) |
| Windows | Microsoft C++ Build Tools + WebView2 (auto-installed on Win 11) |
| Linux | `webkit2gtk-4.1`, `librsvg2-dev`, `libssl-dev`, `build-essential` |

Then everywhere:
```bash
# Install Rust (https://rustup.rs)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install Node 20+ (https://nodejs.org)

# Install Tauri CLI
cd desktop
npm install
```

### 2. Generate app icons (one time, from your logo)

```bash
cd desktop
npm run icon -- ../client/public/icon-512.png
```

This creates `src-tauri/icons/` with all platform-specific sizes. Don't commit the icons folder — it's regenerated from the source PNG.

### 3. Updater signing keys — ALREADY GENERATED

Public key is already embedded in `src-tauri/tauri.conf.json` under `plugins.updater.pubkey`.

The matching **private key** is stored locally (gitignored) at:
```
private_assets/desktop-signing/TAURI_SIGNING_PRIVATE_KEY.txt
```

**To enable production releases, add this to your GitHub repo Secrets:**

1. Open https://github.com/DaMoJo09/PSCoMiXXEcosystem/settings/secrets/actions
2. Click "New repository secret"
3. Name: `TAURI_SIGNING_PRIVATE_KEY`
4. Value: paste the entire contents of `private_assets/desktop-signing/TAURI_SIGNING_PRIVATE_KEY.txt`
5. (Password was empty during generation, so `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` is **not required** — the workflow already handles a blank password.)

⚠️ **Back up the private key file to a password manager.** If you lose it, you can never push updates to existing installs again — they'll be permanently stranded on whatever version they have.

After uploading to GitHub Secrets, you can safely delete the local copy if you want, BUT only after you've backed it up somewhere safe.

## Local development

```bash
cd desktop
npm run dev
```

Opens a native window pointing at `https://pscomixx.com`. Hot reload comes from the website, not the shell.

## Local production build (test only)

```bash
cd desktop
npm run build
```

Outputs installers to `src-tauri/target/release/bundle/`. These will be **unsigned** — Mac/Windows will warn users. Use GitHub Actions for real releases.

## Production release flow

1. Bump `version` in both `desktop/package.json` and `desktop/src-tauri/tauri.conf.json`.
2. Commit + tag: `git tag desktop-v0.1.0 && git push origin desktop-v0.1.0`.
3. The `.github/workflows/desktop-release.yml` workflow runs automatically:
   - Builds on `macos-latest`, `windows-latest`, `ubuntu-22.04`.
   - Creates a GitHub Release with `.dmg`, `.msi`, `.exe`, `.AppImage`, `.deb` attached.
   - Uploads `latest.json` updater manifest so existing installs auto-update.

## How auto-updates actually work

On every launch, the desktop app calls `check_for_updates()` (see `src-tauri/src/lib.rs`). That function:

1. Hits `https://github.com/DaMoJo09/PSCoMiXXEcosystem/releases/latest/download/latest.json` (the manifest produced by `createUpdaterArtifacts: true`).
2. If a newer version exists, verifies the cryptographic signature using the embedded public key.
3. Downloads the platform-specific update package in the background.
4. Installs it and restarts the app silently.

So your update flow is: **bump version → tag → push → users get the update on next launch.** No manual user action.

Note: this only updates the *native shell*. The web content (everything inside the window) updates instantly on every push to `pscomixx.com`. You only need a new desktop release when you change native behavior — window chrome, icon, signing key, plugins, etc.

## Code signing (optional, recommended before public launch)

| Platform | Cost | GitHub secrets needed |
|---|---|---|
| **macOS** (Apple Dev acct) | $99/yr | `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`, `APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID` |
| **Windows** (EV cert) | ~$300–400/yr | `WINDOWS_CERTIFICATE`, `WINDOWS_CERTIFICATE_PASSWORD` |

Without these, the app still works — users just click past one OS warning on first launch.

## What this does NOT do

- Does **not** bundle a local server. The app needs internet to reach pscomixx.com.
- Does **not** ship offline drafts (yet). Phase 4 work.
- Does **not** auto-install on user machines without code-signing (Phase 3).
