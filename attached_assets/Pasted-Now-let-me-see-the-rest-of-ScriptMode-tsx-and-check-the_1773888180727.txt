**What CoMiXX needs to handle:**

1. **Detect `type: "comic-script"`** — trigger Mode Picker (Comic / VN / CYOA)
2. **Read `script_data.pages`** — each page has panels with structured dialogue, SFX, narrations, and image refs
3. **Dialogue styles are pre-detected**: ALL CAPS = `"shout"`, parenthetical = `"whisper"`, angle brackets = `"thought"`, default = `"normal"`
4. **SFX intensity is pre-calculated**: 1-3 chars = `"small"`, 4-6 = `"medium"`, 7+ = `"large"`
5. **`suggested_layout.size`** tells you panel sizing: single panel on page = `"splash"`, 4+ dialogue lines = `"large"`, etc.
6. **`script_data.assets[]`** bundles all referenced images with their `ref_key` matching `img_refs[]` in panels
7. **`script_data.metadata.characters[]`** gives you the unique character list for sprite grouping (VN) or bubble color-coding (Comic)
8. **`mode_hints`** tells you which generators the script supports — `cyoa.branching: false` means no `[CHOICE:]` tags were found
9. **Individual assets are ALSO exported separately** with proper `asset_tag` values, so they show up in the Asset Browser folders independently
10. **`script_data.version`** increments on re-export — use this for diff-based merging (update dialogue without overwriting manually placed art)

**New fields on ALL asset exports (not just scripts):**
- `asset_tag` — one of the 21 tags (e.g. `"character-art"`, `"fx-overlay"`, `"background"`)
- `project_id` — target CoMiXX project (null until user selects one)
- `target_page` — specific page number for placement
- `source_panel_id` — for round-trip returns

**Friction point**: The `script_data` structure should be validated on arrival. If PressPlays changes the shape (adds fields, renames keys), CoMiXX should check `script_data.version` and handle gracefully. A shared JSON schema or version check would prevent silent breakage.

**Cross-mode flow**: Users can now send images from ANY PressPlays mode (Character Creator, Graffiti, Studio, BG FX, Filters) directly into Script Mode's asset gallery via the "Send To → Script" menu. This means characters and backgrounds get tagged and bundled with the script before export.
