Overview
PSStreaming is the viewing/distribution platform for content created in PSCoMiXX. When creators publish content in PSCoMiXX, it should automatically appear on PSStreaming.

│    PSCoMiXX      │         │   PSStreaming    │

│                  │ Publish │                  │
│  pscomixx.com    │         │ psstreaming.com  │
└──────────────────┘         └──────────────────┘

PART 1: CONTENT SYNC
1.1 Publish Content
When a creator clicks "Publish" in PSCoMiXX, send the content to PSStreaming:

POST https://psstreaming.com/api/replit/sync/content
Content-Type: application/json
x-webhook-secret: whsec_45923106c2f0da38c1ec0d10e92accd6666bfeb3610c84de0144c56933bc3dc6

1.3 Scheduled Publishing
To schedule content for future release:

POST https://psstreaming.com/api/replit/sync/content/scheduled
Content-Type: application/json
x-webhook-secret: whsec_45923106c2f0da38c1ec0d10e92accd6666bfeb3610c84de0144c56933bc3dc6
{
  "content_id": "unique-id",
  "content_type": "comic",
  "title": "Coming Soon Comic",
  "publish_at": "2026-04-01T18:00:00Z",
  ...rest of content bundle
}
Response
{
  "success": true,
  "content_id": "unique-id",
  "status": "scheduled",
  "scheduled_at": "2026-04-01T18:00:00Z"
}
1.4 Update Existing Content
Use the same endpoint with an existing content_id:

POST https://psstreaming.com/api/replit/sync/content
If the content_id already exists, it will update instead of create.
