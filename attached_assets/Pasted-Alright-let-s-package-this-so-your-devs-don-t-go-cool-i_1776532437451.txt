# PRESS START CoMiXX + Motion Studio + FX

## UNIFIED CREATION ENGINE — BUILD DIRECTIVE

---

# 1. CORE PHILOSOPHY (THIS IS NON-NEGOTIABLE)

You are NOT building:

* a comic editor
* a motion tool
* a drawing canvas

You are building:

> **ONE CREATION ENGINE where different modes unlock different capabilities**

---

## Golden Rule:

> **Same canvas. Same tools. Different capabilities layered on top.**

If anything feels like:

* “this mode has worse drawing”
* “this tool works differently over here”
* “I have to relearn stuff”

👉 It is WRONG. Fix it.

---

# 2. SYSTEM ARCHITECTURE

## ONE SHARED ENGINE

All modes MUST use:

* INKBLADE Brush Engine
* Vector Line System
* Layer System
* Transform System
* Masking / Clipping
* Rulers / Snapping
* Asset Pipeline

---

## Modes are NOT separate apps

They are **tool overlays**

```plaintext

 ├── Ink Mode
 ├── Color Mode
 ├── Motion Mode
 ├── FX Mode
 ├── Text Mode
```

# 3. USER EXPERIENCE GOAL

* Create (rect, angled, bezier)
* Split / merge
* Adjustable gutters
* Border styling
* Reshape AFTER content is added
* Mask contents automatically
* Optional overflow (break panel borders)

---

### Behavior rules:

* Drawing inside panel = auto clipped
* Dragging asset into panel = auto masked
* Resizing panel = content stays intact

### ADD:

#### Panel Flow Assistant (later phase)
