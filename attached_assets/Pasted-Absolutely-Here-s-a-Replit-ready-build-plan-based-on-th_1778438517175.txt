# Phase 2: Age Gate + COPPA Flow

## Signup Must Ask

```txt
Date of birth
User type: Student / Creator / Teacher / Parent / Admin
School affiliation if applicable
Parent email if under 13
```

## Age Logic

```txt
Under 13:
- Require parent consent
- Block marketplace
- Block public publishing unless approved
- Block AI tools until parent consent is verified

13–17:
- Allow student account
- Limit monetization
- Require safe publishing rules
- No public profile by default

18+:
- Creator account
- Full marketplace/publishing access
```

# Phase 4: Account Deletion

Required for Apple and Google. Not optional, because apparently app stores enjoy “basic user rights.” Weird.

## Build

```txt
/settings/account/delete
```

## User Flow

1. User clicks delete account.
2. App explains what gets deleted.
3. App explains what may be retained for legal/safety reasons.
4. User confirms with password.
5. Account enters deletion queue.
6. User gets confirmation email.
7. Admin can see deletion request status.

## Database Tables

```sql
account_deletion_requests
- id
- user_id
- status
- requested_at
- completed_at
- retained_data_reason
```

# Replit Prompt

Paste this into Replit:

```txt
Build a full compliance management system for the Press Start / MADMIXEDMEDIA ecosystem.

Stack:
- React frontend
- Express backend
- PostgreSQL database
- Drizzle ORM
- Tailwind CSS
- Role-based admin dashboard

The system must support five domains:
1. pscomixx.com
2. pscomixx.online
3. madmixedmedia.com
4. pressstart.tech
5. psstreaming.com

Build the following modules:

1. Legal Document Manager
Create editable legal pages for Privacy Policy, Terms of Service, COPPA Notice, FERPA Notice, DMCA Policy, Community Guidelines, AI Disclosure, Account Deletion Policy, and Data Processing Addendum. Include document versioning, effective dates, and user acceptance tracking.

2. Age Gate and COPPA Flow
At signup, collect birthdate, account type, school affiliation if applicable, and parent email for users under 13. Create age bands for under 13, 13–17, and 18+. Restrict features based on age. Require parental consent for under-13 users before AI tools, public publishing, marketplace access, or data sharing.

3. AI Consent System
Before any AI generation, display a consent modal explaining provider usage, data processing, storage, and third-party sharing. Store consent by user, provider, version, and timestamp. Allow consent revocation.

4. Account Deletion
Create an in-app and web account deletion flow. Users must be able to request deletion from settings. Track request status, completion date, retained data reason, and confirmation emails.

5. DMCA System
Create public DMCA takedown and counter-notice forms for psstreaming.com. Include claimant info, original work description, infringing URL, required legal checkboxes, and electronic signature. Add repeat-infringer policy tracking and admin review queue.

6. UGC Moderation
Add report functionality for comics, HOPs, visual novels, trading cards, music uploads, comments, profiles, and marketplace listings. Create moderation dashboard with status, assigned reviewer, actions, and audit logs.

7. FERPA / School Compliance
Create school district profiles, DPA tracking, student data logs, data export tools, and data deletion tools. Track which school has signed which DPA version.

8. Business Footer API
Create an API endpoint that returns required legal footer links and business contact info for each domain.

9. Intercompany Agreement Tracker
Track agreements between MAD MIXED MEDIA LLC and Press Start Gaming Inc., including IP License Agreement, Service Agreement, Revenue Sharing Agreement, Data Processing Agreement, board approvals, and fair-market-value documentation.

10. Roles
Create roles:
- Super Admin
- Compliance Admin
- Moderator
- School Admin
- Teacher
- Parent
- Student
- Creator

11. Security
Add authentication, role-based permissions, audit logs, rate limiting, input validation, and admin-only access for sensitive records.

12. Output
Create all database schemas, backend routes, frontend pages, admin dashboard screens, and seed data. Make the UI clean, black-and-white, minimal, and professional.
```
